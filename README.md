# Personal Portfolio Website

This repository contains a one-page portfolio website built with HTML, CSS, and JavaScript. It is designed to present professional work, skills, and contact details in a polished, modern format.

## Overview

The website includes:
- A hero section with animated title text and a profile image.
- A skills section highlighting tools, languages, and development strengths.
- A projects section showcasing featured web and desktop applications.
- A contact section with direct links to GitHub and LinkedIn.
- A sticky side navigation slider that highlights the active section while scrolling.

## Features

- Glassmorphism-inspired UI with translucent cards and blurred backgrounds.
- Smooth scrolling navigation to page sections.
- Scroll-triggered reveal animations for section content.
- Typing effect for the hero title and section headings.
- Compact project cards and responsive layout for mobile devices.

## Technologies

- HTML5 for page structure.
- CSS3 for layout, styling, and responsive design.
- JavaScript for navigation, scroll animations, and interactive effects.

## Project Structure

```text
Portfolio Website/
├── index.html        # Main page markup
├── style.css         # Visual styling and layout
├── script.js         # Navigation and animation logic
├── README.md         # Project documentation
└── images/           # Profile picture and skill icons
```

## Getting Started

To view the website locally:
1. Open `index.html` in a web browser.
2. Alternatively, host the folder using any static file server or deployment service.

## Notes

This project is intended as a portfolio showcase with an emphasis on visual presentation and interaction. The structure is suited for future expansion with additional projects, sections, or backend integrations.
