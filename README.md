# Personal Portfolio Website

A lightweight one-page portfolio built with HTML, CSS, and JavaScript. It combines modern glassmorphism styling with smooth scrolling and animated section reveal effects.

## What’s Included

- A hero section with animated title text and a profile image.
- Skills and tools overview with compact skill cards.
- A projects showcase with featured work links.
- Contact details with direct GitHub and LinkedIn access.
- A sticky side slider for section navigation and active-state feedback.

## Highlights

- Glass-style cards with blur and soft borders.
- Scrolling reveals and typing animation for headings.
- Responsive layout for mobile and desktop.
- Clickable hero image to open the GitHub profile.

## Project Structure

```text
Portfolio Website/
├── index.html
├── style.css
├── script.js
├── README.md
└── images/
```

This site is designed as a clean, reusable portfolio base and can be extended with additional sections or visual refinements.
